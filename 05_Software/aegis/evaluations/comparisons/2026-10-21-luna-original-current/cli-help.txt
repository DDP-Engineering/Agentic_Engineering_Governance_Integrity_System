usage: aegis [-h] [--version]
             {init,task,req,anchor,evolution,check,test,report,summary,brief,components,diagram,trace,explain,status} ...

AEGIS companion CLI - a scaffolder and a reporter.

positional arguments:
  {init,task,req,anchor,evolution,check,test,report,summary,brief,components,diagram,trace,explain,status}
    init                finish installing the payload in this repo
    task                create a task journal
    req                 create a requirement file
    anchor              record Git-visible repository state for one task
    evolution           compare repository state with a task anchor
    check               run the heuristic check catalog (advisory: findings
                        never fail it)
    test                run a configured command (default: test); exit mirrors
                        it
    report              append the delivery summary to a task journal
    summary             print a compact recorded stage summary (read-only)
    brief               print a bounded durable resume brief
    components          list component knowledge titles and paths
    diagram             draw the requirement register as a Mermaid coverage
                        map
    trace               export the requirement register as a traceability
                        matrix
    explain             show what governs one repository path
    status              list open task journals, or show one

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit

# AEGIS extension

For software work governed by the checkout's installed `.agentic/aegis.py`, or when AEGIS is requested, load the `aegis` skill. Read root AGENTS.md and installed workflow instructions. Use the `aegis` MCP tools for workflow operations; preserve existing user scope and authorization. This extension does not initialize governance, choose a model, or authorize Git delivery. Unrelated work remains governed by its own instructions.

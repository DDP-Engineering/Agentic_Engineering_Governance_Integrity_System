# AEGIS extension

For changes that add or change a durable product rule (logic, data, security, performance, integrations or a product-wide UI rule) in a checkout with an installed `.agentic/aegis.py`, or when AEGIS is requested, load the `aegis` skill. Make bug fixes that restore intended behavior, local UI adjustments, refactors and test, docs or tooling fixes directly. Read root AGENTS.md and installed workflow instructions. Use the `aegis` MCP tools for workflow operations; preserve existing user scope and authorization. This extension does not initialize governance, choose a model, or authorize Git delivery. Unrelated work remains governed by its own instructions.

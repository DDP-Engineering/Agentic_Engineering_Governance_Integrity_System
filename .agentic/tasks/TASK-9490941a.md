## Design

Components touched: the validation and evidence CLI only.

- REQ-UX-48bb759b. `DEVIATION_RE` requires a member of `KNOWN_STAGES` after the
  token instead of `\w+`, and a `(?<![\w-])` guard in front of it. The stage is
  mandatory: deliver found that allowing the stage-less `DEVIATION:` lets a
  journal quoting the marker report itself, and the stage is the only thing
  that separates a record from a mention. The match consumes the token and the
  space and the stage is matched by a lookahead, so the harvested text keeps
  its existing `stage: what` shape — the report layout does not move.
  `recorded_deviations` starts a new entry from a non-bullet line instead of
  discarding it, which is what makes the bare contract line visible while
  leaving indented continuations joining as before. Idempotence is unchanged and now asserted:
  `cmd_report` writes entries back with the token stripped, so a second report
  cannot re-harvest them.
- REQ-FUNC-6b4ff1ad, REQ-FUNC-0f4eb4c5. One shared classifier, `coverage_class`,
  moves up beside `manual_method` and becomes the single place the precedence
  lives. `check_requirement_links` calls it for its branch and `link_failure`
  for its per-entry messages, so its findings are unchanged line for line; the
  diagram and `explain` render the same verdict as a label. Two classes are
  added — `broken` for a linked test that does not resolve, matching the WARN,
  and `draft` for a record `check` is deliberately silent about.

Rejected: leaving the two functions separate and merely aligning their fields.
It fixes today's two divergences and leaves the next edit free to reintroduce
one, which is exactly how these two drifted apart.

Test seams: `05_Software/aegis/tests/test_run_report.py`, beside the existing
diagram and report tests, calling the module-level functions directly for the
classifier table and driving `report` end to end for the harvest.

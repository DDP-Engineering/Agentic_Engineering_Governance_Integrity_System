## Design

- Component: extend the Core CLI lifecycle with `cmd_components`; share safe page loading while keeping the catalogue's title projection independent from `knowledge_components` claim parsing (REQ-FUNC-8ec7a0c7).
- Interface: register exactly one no-argument top-level `components` command; print `<bounded-printable-title-or-stem>\t.agentic/knowledge/<file>.md` using the lexical catalogue path in deterministic order (REQ-FUNC-8ec7a0c7).
- Empty and failure behavior: an empty directory prints `no component knowledge pages`; unreadable UTF-8, filesystem errors, link escapes, resolution loops, or non-printable catalogue paths use the existing one-line `UserError` path and emit no partial catalogue (REQ-FUNC-8ec7a0c7).
- State: the command reads only `.agentic/knowledge/*.md`, performs no Git, configuration, command, repository write, or network operation, and returns 0 on a readable empty or populated catalogue (REQ-FUNC-8ec7a0c7).
- Workflow: frame, specify, and design use the catalogue for discovery; build and validate use it only for an additional unnamed component; adoption uses it to inventory existing pages; deliver does not use it (REQ-FUNC-9db20045).
- Guidance: canonical CLI help/reference, workflow command list, package and user CLI documentation explain the single command without suggesting metadata or automatic routing (REQ-UX-62a24243).
- Tests: isolated copied-payload tests cover ordering, title-only extraction, normalization and bounds, stem fallback, lexical paths and link escapes, empty output, and byte-for-byte no-write behavior; structural tests cover parser/help/reference and stage-placement guidance (REQ-FUNC-8ec7a0c7, REQ-FUNC-9db20045, REQ-UX-62a24243).
- Expected implementation files: canonical `aegis.py`, `CLI.md`, `AGENTS.md`, frame/specify/design/build/validate/adopt steps, `test_cli_core.py`, `test_structure.py`, package README, user CLI reference, Core CLI knowledge, and changelog.
- Rejected alternative: metadata, a generated or hand-maintained registry, and nested catalogue operations add maintenance and interface surface before title-only discovery proves insufficient (REQ-FUNC-8ec7a0c7).
- Architecture: only one new command entry point is added; it shares safe page loading but not claim parsing, and introduces no separate subsystem or data format (REQ-FUNC-8ec7a0c7).
